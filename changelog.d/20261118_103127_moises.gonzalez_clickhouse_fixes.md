### Added

- The default (admin) user can use a custom username by setting
  `CLICKHOUSE_DEFAULT_USER_NAME`.
- The TTL for `text_log`, `error_log` and `query_log` can be configured with
  `CLICKHOUSE_LOG_RETENTION_DAYS`. All the other system log tables have been
  disabled.
- A new `CLICKHOUSE_SERVER_CONFIG_OVERRIDE` can be used to insert arbitraty xml
  content in configuration fragment with low priority to allow custom overrides.

### Changed

- The user configuration is no longer overwritten and instead is defined as
  configuration fragment in `users.d/`.
- The user creation for `CLICKHOUSE_USERS` is handled by the `community.clickhouse.*` modules.
- The default logging level is set to warning for both `text_log` system table
  and the clickhouse base logger.
